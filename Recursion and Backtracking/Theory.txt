The Master Backtracking Template:
You can solve almost every backtracking problem with this:

solve(state){
    if(answer formed){
        save answer
        return
    }

    for(each possible choice){
        if(choice is valid){
            make choice
            solve(next state)
            undo choice
        }
    }
}

Now map it to problems:

| Problem        | State        | Choices               |
| -------------- | ------------ | --------------------- |
| Subsequences   | index        | Pick / Skip           |
| Binary Strings | position     | 0 / 1                 |
| N Queens       | row          | Every column          |
| Permutations   | index        | Every unused element  |
| Sudoku         | empty cell   | Digits 1–9            |
| Rat in Maze    | current cell | Up, Down, Left, Right |


























What is a Subsequence?

A subsequence is obtained by choosing or skipping each element while maintaining the original order.

Example:

Array: [1, 2, 3]

Subsequences:

[]
[1]
[2]
[3]
[1,2]
[1,3]
[2,3]
[1,2,3]

Notice:

Order is maintained.
Elements need not be contiguous.
Total Number of Subsequences

For an array of size n:

2^n

Reason:

Each element has 2 choices:

Take
Don't take

So,

2 × 2 × 2 ... (n times)

= 2^n
Generic Recursion Template

At every index:

          index i
         /       \
      Take      Don't Take

Code skeleton:

solve(i):

    if(i == n){
        process answer
        return;
    }

    // Take
    add(arr[i]);
    solve(i+1);

    // Backtrack
    remove last element;

    // Don't Take
    solve(i+1);
Backtracking

Always remember:

Choose
Explore
Unchoose

ls.add(arr[i]);

solve(i+1);

ls.remove(ls.size()-1);

Pick / Not Pick Pattern
solve(i)

        i
      /   \
   Pick   Not Pick

Almost every subsequence problem follows this.

Important Base Case
if(i == n){
    // Process answer
    return;
}

Never access:

arr[i]

after

i == n
Time Complexity

Number of recursive calls:

O(2^n)

Space:

O(n)

because recursion depth is at most n.

Master Template
void solve(int i){

    if(i == n){
        // answer
        return;
    }

    // Take
    pick(arr[i]);

    solve(i+1);

    unpick(arr[i]);

    // Don't Take
    solve(i+1);
}
