Why bit-checking works
Expression: (mask & (1 << i)) != 0
1 << i creates a number with only the i-th bit ON. AND checks whether the same bit is ON in the mask.
Tip: change the array to values like 1,2,3,4. For a smooth experience, keep the array length at 8 or less.
