WINDOW FUNCTIONS:
	Basic Structure:
	
	FUNCTION() OVER (
		PARTITION BY ...
		ORDER BY ...
	)
	PARTITION BY → Divide rows into groups, but DON'T collapse them
	ORDER BY     → Decide the order inside the window
	1. ROW_NUMBER()
	Use when: You need a unique sequential number for every row.

	ROW_NUMBER() OVER (
		PARTITION BY department
		ORDER BY salary DESC
	)

	Result:
	90000 → 1
	80000 → 2
	80000 → 3
	60000 → 4
	Memory: ROW_NUMBER = unique numbering


	2. RANK()
	Use when: You want ranking where ties get the same rank and gaps appear.
	90000 → 1
	80000 → 2
	80000 → 2
	60000 → 4
	Memory: RANK = ties + gaps

	3. DENSE_RANK()

	Use when: You want ranking where ties get the same rank but no gaps.

	90000 → 1
	80000 → 2
	80000 → 2
	60000 → 3

	Memory: DENSE_RANK = ties + no gaps

	The 3 Ranking Functions

	Memorize this:

	ROW_NUMBER  → 1 2 3 4
	RANK        → 1 2 2 4
	DENSE_RANK  → 1 2 2 3
	4. SUM() OVER()

	Use when: You want a running total without collapsing rows.

	SUM(salary) OVER (
		ORDER BY date
	)

	Example:

	100 → 100
	200 → 300
	150 → 450
	300 → 750

	Memory: SUM OVER = running/partitioned total

	5. AVG() OVER()

	Use when: You want an average while keeping every row.

	AVG(salary) OVER (
		PARTITION BY department
	)

	Example:

	Ravi   60000 → dept_avg 76666
	Priya  80000 → dept_avg 76666
	Arun   90000 → dept_avg 76666

	Memory: AVG OVER = group average without GROUP BY

	6. LAG()

	Use when: You need the previous row's value.

	LAG(salary) OVER (
		ORDER BY date
	)

	Example:

	Date | Sales | Previous
	-----+-------+---------
	1    | 100   | NULL
	2    | 200   | 100
	3    | 150   | 200
	4    | 300   | 150

	Memory: LAG = look backward

	7. LEAD()

	Use when: You need the next row's value.

	LEAD(salary) OVER (
		ORDER BY date
	)

	Example:

	Date | Sales | Next
	-----+-------+-----
	1    | 100   | 200
	2    | 200   | 150
	3    | 150   | 300
	4    | 300   | NULL

	Memory: LEAD = look forward

	8. FIRST_VALUE()

	Use when: You want the first value in the window.

	FIRST_VALUE(salary) OVER (
		PARTITION BY department
		ORDER BY salary DESC
	)

	Memory: FIRST_VALUE = first row's value

	9. LAST_VALUE()

	Use when: You want the last value in the window.

	LAST_VALUE(salary) OVER (...)

	Important: LAST_VALUE() is trickier because window frames matter. We'll learn this separately.

	Memory: LAST_VALUE = last value in the window
	ROW_NUMBER(),RANK(),DENSE_RANK()

CTE Q8 — CTE + Window Function
Using employees, write a query that:
Creates a CTE containing each employee's department average salary using a window function.
Returns only employees whose salary is greater than their department average.

Expected columns:
name | department | salary | avg_salary

This is an important pattern because it combines:
CTE
 +
Window Function
 +
WHERE

Solution:
	with cte as (
		select name,department,salary,
		avg(salary) over (
			partition by department
		) as avgsal
		from employees
	)
	select * from cte c
	where c.salary > c.avgsal;
	

Why this is a great pattern

You used:

AVG() OVER(PARTITION BY department)
        ↓
keeps every employee
        ↓
CTE gives us avgsal as a column
        ↓
outer WHERE compares salary > avgsal



WINDOW FUNCTIONS Revision:

Window Q1 — ROW_NUMBER()

Using employees:

Give every employee a row number within their department, with the highest-paid employee getting number 1.

Return:

name | department | salary | rn

For example:

Arun  | IT | 90000 | 1
Priya | IT | 80000 | 2
Ravi  | IT | 60000 | 3

Solution:
	with cte as (
		select name,department,salary,
		row_number() over (
			partition by department
			order by salary desc
		) as rn
		from employees
	)
	select * from cte;
	
	(or)
	
	select name,department,salary,
		row_number() over (
			partition by department
			order by salary desc
		) as rn
	from employees;
	
	But you do need the CTE/subquery if you want to filter by rn, for example:
	WHERE rn = 1
	because a window-function result generally can't be filtered in the same query level with WHERE.
	That gives us the classic pattern:

	ROW_NUMBER()
		↓
	CTE
		↓
	WHERE rn = 1
		↓
	highest-paid employee per department

Memorize this
FIRST_VALUE + ASC
→ lowest

FIRST_VALUE + DESC
→ highest

LAST_VALUE + ASC
→ highest

LAST_VALUE + DESC
→ lowest

LAST_VALUE()
+
