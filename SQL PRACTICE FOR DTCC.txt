WINDOW FUNCTIONS:
	Basic Structure:
	
	FUNCTION() OVER (
		PARTITION BY ...
		ORDER BY ...
	)
	PARTITION BY → Divide rows into groups, but DON'T collapse them
	ORDER BY     → Decide the order inside the window
	1. ROW_NUMBER()
	Use when: You need a unique sequential number for every row.

	ROW_NUMBER() OVER (
		PARTITION BY department
		ORDER BY salary DESC
	)

	Result:
	90000 → 1
	80000 → 2
	80000 → 3
	60000 → 4
	Memory: ROW_NUMBER = unique numbering


	2. RANK()
	Use when: You want ranking where ties get the same rank and gaps appear.
	90000 → 1
	80000 → 2
	80000 → 2
	60000 → 4
	Memory: RANK = ties + gaps

	3. DENSE_RANK()

	Use when: You want ranking where ties get the same rank but no gaps.

	90000 → 1
	80000 → 2
	80000 → 2
	60000 → 3

	Memory: DENSE_RANK = ties + no gaps

	The 3 Ranking Functions

	Memorize this:

	ROW_NUMBER  → 1 2 3 4
	RANK        → 1 2 2 4
	DENSE_RANK  → 1 2 2 3
	4. SUM() OVER()

	Use when: You want a running total without collapsing rows.

	SUM(salary) OVER (
		ORDER BY date
	)

	Example:

	100 → 100
	200 → 300
	150 → 450
	300 → 750

	Memory: SUM OVER = running/partitioned total

	5. AVG() OVER()

	Use when: You want an average while keeping every row.

	AVG(salary) OVER (
		PARTITION BY department
	)

	Example:

	Ravi   60000 → dept_avg 76666
	Priya  80000 → dept_avg 76666
	Arun   90000 → dept_avg 76666

	Memory: AVG OVER = group average without GROUP BY

	6. LAG()

	Use when: You need the previous row's value.

	LAG(salary) OVER (
		ORDER BY date
	)

	Example:

	Date | Sales | Previous
	-----+-------+---------
	1    | 100   | NULL
	2    | 200   | 100
	3    | 150   | 200
	4    | 300   | 150

	Memory: LAG = look backward

	7. LEAD()

	Use when: You need the next row's value.

	LEAD(salary) OVER (
		ORDER BY date
	)

	Example:

	Date | Sales | Next
	-----+-------+-----
	1    | 100   | 200
	2    | 200   | 150
	3    | 150   | 300
	4    | 300   | NULL

	Memory: LEAD = look forward

	8. FIRST_VALUE()

	Use when: You want the first value in the window.

	FIRST_VALUE(salary) OVER (
		PARTITION BY department
		ORDER BY salary DESC
	)

	Memory: FIRST_VALUE = first row's value

	9. LAST_VALUE()

	Use when: You want the last value in the window.

	LAST_VALUE(salary) OVER (...)

	Important: LAST_VALUE() is trickier because window frames matter. We'll learn this separately.

	Memory: LAST_VALUE = last value in the window
	ROW_NUMBER(),RANK(),DENSE_RANK()

CASE WHEN:
Basic structure:
CASE
    WHEN condition THEN result
    WHEN condition THEN result
    ELSE result
END

CASE + Aggregate:

This is where CASE becomes very powerful.
Suppose you want to count how many employees have salary above 70,000:
	SELECT
		COUNT(
			CASE
				WHEN salary > 70000 THEN 1
			END
		) AS high_salary_count
		FROM employees;
	
The CASE returns 1 only for employees satisfying the condition.


CASE + GROUP BY:
Suppose:
For each department, count high-salary employees.

	SELECT
		department,
		COUNT(
			CASE
				WHEN salary > 70000 THEN 1
			END
		) AS high_salary_employees
	FROM employees
	GROUP BY department;

This pattern is called conditional aggregation.

	from cte
	group by department;


The important pattern:
This is a very useful interview pattern:
Window Function
      ↓
calculate something for each row
      ↓
	 CTE
      ↓
	CASE
      ↓
GROUP BY + COUNT/SUM


CASE Q7 — Last one
Let's make this closer to a real interview problem.
Using employees:
For each department, find the percentage of employees earning more than 70,000.
Return:
department | high_salary_percentage
For example, if IT has 4 employees and 2 earn above 70,000:
IT | 50
Use CASE, COUNT, and GROUP BY.

Solution:
	select department,count(
		case
			when salary > 70000 then 1
		end
	) * 100.0 count(*) as high_salary_percentage
	from employees
	group by department;






Stored Procedures — Part 1

First, understand the idea.

What is a Procedure?
A stored procedure is a saved SQL program inside the database that you can execute whenever you want.

Think:
Normal SQL:
write query → execute → done

Procedure:
write SQL program → SAVE it → CALL it whenever needed
Basic Syntax — MySQL

DELIMITER //
CREATE PROCEDURE procedure_name()
BEGIN
    -- SQL statements
END //
DELIMITER ;

Then execute it:
CALL procedure_name();

Example
DELIMITER //
CREATE PROCEDURE show_employees()
BEGIN
    SELECT * FROM employees;
END //
DELIMITER ;

CALL show_employees();


That's the basic pattern.


Procedures with Parameters:
This is very important for exams.
Suppose we want to give a department and retrieve its employees.

DELIMITER //
CREATE PROCEDURE get_employees_by_department(
    IN dept_name VARCHAR(50)
)
BEGIN
    SELECT name, salary
    FROM employees
    WHERE department = dept_name;
END //
DELIMITER ;

CALL get_employees_by_department('IT');


Remember:
	IN     → value goes INTO procedure
	OUT    → value comes OUT of procedure
	INOUT  → value goes in AND comes out

We'll learn OUT and INOUT separately.

Procedure Q3 — IN + Calculation
Create a procedure called:
get_salary_details
It should accept:
IN emp_id
and display:
name

annual_salary

Where:

	delimiter //
	create procedure get_salary_details(

Procedure Q4 — IF / ELSE
Now we're getting into exam-important procedures.
Create a procedure:
check_salary
It accepts:
IN emp_id

It should display:
name | salary | salary_status

Rules:
salary >= 80000 → 'High Salary'
salary >= 60000 → 'Medium Salary'
otherwise       → 'Low Salary'

Important: This time, use procedural IF / ELSEIF / ELSE, not CASE.

Solution:
	delimiter //
	create procedure check_salary(
		in emp_id int
	)
	begin
		declare emp_id int;
		declare emp_name varchar(100);
		
		select name,salary,
		into emp_name, emp_salary
		from employees
		where id = emp_id;
		
		if salary >= 80000 then 
			select emp_name as name, emp_salary as salary,
			'High Salary' as salary_status;
		
		else if salary >= 60000 then
			select emp_name as name, emp_salary as salary,
			'Medium Salary'	as salary_status;
		
		else 
			select emp_name as name, emp_salary as salary,
			'Low Salary' as salary_status;
		
		end if;
	end //
	delimiter;
	
	call check_salary(3);


The important pattern for a procedure IF:

IF condition THEN
    statements;
ELSEIF condition THEN
    statements;
ELSE
    statements;
END IF;



Don't confuse these two
CASE inside SELECT:
CASE
    WHEN salary >= 80000 THEN 'High'
    ELSE 'Low'
END

Procedural IF:
IF emp_salary >= 80000 THEN
    ...
ELSE
    ...
END IF;

PROCEDUREs are kept aside temporarily.



DATE FUNCTIONS:
We'll use this imaginary table: employees

id | name  | hire_date  | salary
---+-------+------------+-------
1  | Ravi  | 2022-03-15 | 60000
2  | Priya | 2021-07-20 | 80000
3  | Arun  | 2023-01-10 | 90000
4  | Kiran | 2020-11-05 | 70000

1. YEAR()
Use: Extract the year from a date.

SELECT
    name,
    YEAR(hire_date) AS hire_year
FROM employees;

Result:
Ravi  → 2022
Priya → 2021
Arun  → 2023
Kiran → 2020

Similarly:
MONTH(hire_date) gives the month number.
DAY(hire_date) gives the day.

Memorize:
YEAR(date)  → year
MONTH(date) → month
DAY(date)   → day




Q1
Using employees:
Display the employee's name, hire_date, and the year they were hired.
Expected:
name | hire_date | hire_year
Use YEAR().

Solution:
	select name, hire_date,
	year(hire_date) as hire_year
	from employees;
	

Q2 — MONTH()
Display the employee's name, hire_date, and the month number in which they were hired.
Expected:
name | hire_date | hire_month
Use MONTH().

Solution:
	select name, hire_date,
	month(hire_date) as hire_month
	from employees;



Q3 — DAY()
Display the employee's name, hire_date, and the day of the month on which they were hired.
Expected:
name | hire_date | hire_day

Solution:
	select name, hire_date,
	day(hire_date) as hire_day
	from employees;
	


DATEDIFF() tells you the number of days between two dates.
Syntax:
DATEDIFF(later_date, earlier_date)
Example:
DATEDIFF('2026-08-27', '2026-08-20') → 7



Q4 — DATEDIFF()
Using employees:
Find how many days each employee has worked, assuming today is '2026-08-27'.

Return:
name | hire_date | days_worked
Use DATEDIFF().

Solution:
	select name,hire_date,
	datediff('2026-08-27',hire_date)
	as days_worked from employees;


DATE_ADD() is used to add time to a date.
Syntax:
DATE_ADD(date, INTERVAL value unit)
Example:
DATE_ADD(hire_date, INTERVAL 1 YEAR) → adds 1 year.

Common units:
YEAR
MONTH
DAY
WEEK

Q5 — DATE_ADD()
Using employees:
Display each employee's name, hire_date, and the date one year after their hire date.
Expected:
name | hire_date | one_year_later
Use DATE_ADD().

Solution:
	select name,hire_date,
	date_add(hire_date,interval 1 year) as one_year_later
	from employees;



Q6 — DATE_SUB() : Now the opposite.
Display each employee's name, hire_date, and the date 6 months before their hire date.
Use DATE_SUB().

Solution:
	select name,hire_date,
	date_sub(hire_date, interval 6 month)as six_months_earlier
	from employees;


TIMESTAMPDIFF():
This one is very important because unlike DATEDIFF(), it can calculate the difference in years, months, days, hours, etc.
Syntax:
TIMESTAMPDIFF(unit, start_date, end_date)
Example:
TIMESTAMPDIFF(YEAR, hire_date, '2026-08-27')

Q7 — TIMESTAMPDIFF():
Using employees:
Find how many complete years each employee has worked as of 2026-08-27.
Return:
name | hire_date | years_worked
Use TIMESTAMPDIFF().

Solution:
	select name,hire_date,
	timestampdiff(year,hire_date,'2026-08-27')
	as years_worked from employees;


Q8 — Date Filtering
Now let's combine what you've learned.
Find all employees who were hired in 2022.
Return:
name | hire_date
Use YEAR() in the WHERE clause.

Solution:
	select name,hire_date
	from employees
	where year(hire_date);

Q9 — Date Filtering with MONTH()
Find all employees who were hired in July, regardless of the year.
Return:
name | hire_date
Use MONTH() in the WHERE clause.

Solution:
	select name,hire_date from employees
	where month(hire_date) = 7;



Q10 — DATE_ADD() + WHERE
Find employees whose 1-year anniversary falls before 2026-01-01.
In other words, add 1 year to hire_date and check whether that date is before 2026-01-01.
Return:
name | hire_date | anniversary
Use DATE_ADD() in both SELECT and WHERE.

Solution:
	select name,hire_date,
	date_add(hire_date,interval 1 year) as anniversary
	from employees
	where date_add(hire_date) < '2026-01-01';


Important pattern:
If you need to filter using a calculated column:
Calculated in SELECT
       ↓
Need it in WHERE?
       ↓
Repeat expression OR use CTE
